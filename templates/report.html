🛠 Technology Stack

  • Python 3.11
  • Google Gemini API (Structured Output)
  • Pydantic for schema validation
  • Jinja2 for HTML templating
  • JSON as the intermediate data format
  • HTML & CSS dashboard

✅ Verification Strategy

  • Each application is researched using a dedicated research agent.
  • A second verification agent reviews and corrects the initial findings.
  • Pydantic schemas enforce consistent structured output.
  • Official documentation URLs are stored as evidence for every application.
  • The analyzer aggregates results across all researched applications.
  • The final report is generated automatically from verified JSON files.

🚀 Future Improvements

  • Scale the pipeline from 6 applications to the full 100-app dataset.
  • Add parallel processing to reduce research time.
  • Introduce browser-based verification for higher confidence.
  • Generate charts showing API ecosystem trends.
  • Export results to CSV and Markdown in addition to JSON.
